# My Seven Ocean

Pure Marine Luxury & 3D Spatial Experiences — Distribution brand for luxury marine skincare, mists, and fragrances.

## Features
- **3D Kinetic Deck**: Interactive product lineup with isometric and perspective transforms.
- **Spatial Archive**: 3D perspective scroll reveal featuring formulation cards.
- **GSAP Testimonials**: Scroll-driven partner reviews and live counting metrics.
- **Interactive Ocean Bag**: Quick order reservation drawer.
- **Responsive & Optimized**: Light WebP assets and smooth GPU animations.

## Local Development
Run any static file server:
```bash
python -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
